# Leve Emu

Emulador de NES leve que roda no navegador da TV. Cada celular vira controle escaneando o QR code (conexão direta pelo Wi‑Fi via WebRTC).

- TV: abra o site e escolha "Esta tela é a TV"
- Celular: escaneie o QR code, toque em **🎮 Jogo** e envie um `.nes`
- Até 2 jogadores (limite do NES); os demais ficam na fila
