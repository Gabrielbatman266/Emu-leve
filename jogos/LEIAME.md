# Biblioteca do Leve Emu

Os jogos desta pasta aparecem na **Biblioteca** do app (TV, controle e modo celular).

## Jogos incluídos (livres)
- **Concentration Room** e **LJ65**, de Damian Yerrick — software livre (GPL). Veja os arquivos LEIAME de cada um.

## Como adicionar mais jogos
1. Envie o arquivo `.nes`, `.smc` ou `.sfc` para esta pasta (no GitHub: *Add file → Upload files*).
2. Adicione uma linha em `lista.json`, por exemplo:
   `{ "nome": "Meu Jogo", "arquivo": "meu-jogo.sfc", "sistema": "snes" }`

Só coloque aqui jogos que você tem o direito de distribuir (homebrew livre, jogos seus).
Este repositório é público: ROMs comerciais publicadas aqui violam direitos autorais e podem fazer o GitHub remover o repositório.
Para jogar os seus próprios cartuchos, use **📂 Abrir arquivo do aparelho** no app — o arquivo fica só no seu aparelho.
